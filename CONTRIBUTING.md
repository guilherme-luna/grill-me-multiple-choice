# Contributing

This plugin is small on purpose: two skills and no configuration.

If something fails, open an issue with what you ran, what happened and what you expected. Say which Claude Code version you use. One problem per issue, please.

Pull requests are welcome for fixes to a problem described in an issue. Changes that make the skill work outside Claude Code, or that remove the multiple-choice dialog, are out of scope: that is the original `grill-me` by Matt Pocock.
